# security-app-practice

## 概要
COACHTECH 教材 Tutorial 10-6「Webセキュリティ ハンズオン」で作成した成果物です。
CSRF保護とXSS対策をしたお問い合わせフォームを作成。

## 使用技術
- PHP 8.x
- Laravel 10.x
- CSRF 保護（`@csrf`）、XSS 対策（Blade の自動エスケープ）
（**他に使ったものがあれば追記してください**）

## 学んだこと
- bladeの<form>には @csrfでCSRF保護を必ず付け加える。
- XSS対策は{{ $name }}のように書く。{!! !!}を使うとHTMLにフォームへ入力した文字がそのまま出てしまう。
- ページのソースを表示でCSRF保護が正しく機能しているかチェックできる。

## 動作確認
http://localhost/contact　へアクセスしフォームに入力・送信完了するか確認。
さらにページのソースを開き<input type="hidden" name="_token" value="ランダムな文字列">となっていればCSRF保護ができている。
メッセージ欄に<script>alert('XSS')</script>を入力するとそのまま文字列としてメッセージが送信される。

## 詰まったポイントと解決方法
コントローラーに受け取ったデータを完了画面に渡すメソッドを書き忘れてしまったので後から追記した。

## 開発の工夫
フォームが未入力だった時は日本語のエラーメッセージが出るようにコントローラーへ追記した。
